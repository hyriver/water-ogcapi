# Security policy

## Reporting a vulnerability

Report a vulnerability in `water-ogcapi` through
[private vulnerability reporting](https://github.com/hyriver/water-ogcapi/security/advisories/new),
and keep it out of public issues until a fix is out. Include the version, the steps or
code that reproduce it, and what an attacker gains. Leave real API keys out of the
report.

Reports that fit here include an API key or a signed URL reaching a log record, an error
message, a pickle, or a host it was not meant for, and a redirect that carries a
credential.

Problems in the USGS services themselves go to USGS.

## Supported versions

Fixes go to the latest release.
